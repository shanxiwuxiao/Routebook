# Routebook · 路书

> 一个自我驱动的学习助手：它记录你在哪、判断你去哪、推着你往前走。

---

## 这是什么

不是博客，不是笔记软件，也不是课程平台。

**它是一个学习状态机。** 你把一门知识拆成带依赖关系的节点网络，它记录你真实走到哪一步，然后持续告诉你下一步该去哪、该做什么。

核心能力：

| 能力 | 说明 |
|---|---|
| 依赖图 | 节点之间有前置关系，学什么不由顺序决定，由依赖决定 |
| 出口条件 | 每个知识点有"做到什么才算掌握"的验收标准 |
| 规则推荐 | 前置已掌握、自己还没开始的节点，就是你现在该学的 |
| AI 助手 | 在既定路线内做调度和解释（**不负责选节点，只负责说清楚**） |
| 间隔重复 | 已掌握的知识会衰减，到期自动提醒复习 |
| 数据主权 | 全量导出为开放的 JSON / Markdown |

## 两条铁律

这两条贯穿整个项目，写在最前面：

**一、AI 只是翻译官，不是大脑。**
选哪个节点由依赖关系图算出来，AI 只负责把计算结果翻译成人能听懂的建议。把选节点的权力交给 AI，这个产品就废了。

**二、产品迭代路线 = 你的学习路线。**
每个里程碑都对应一个学习节点（见 `docs/08-开发计划.md`）。学完一个技术，才做对应的功能。

> 最坏的结果是：你做出了一个漂亮的网站，但一个知识点没学。
> 最好的结果是：你学到了东西，顺便得到了一个自己天天在用的产品。
